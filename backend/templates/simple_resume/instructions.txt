SIMPLE RESUME TEMPLATE

Key Commands:
- \geometry{margin=0.5in} for default margins (can be changed when user requests)
- \makeheader{name}{contact1}{contact2}{contact3}{contact4} for header with name and contact info
- Name size is hardcoded as \Huge in \makeheader (can be modified in template if needed)
- \entrybullets environment for bullet points
- \item for bullets in template environments
- \href{url}{text} for clickable links

IMPORTANT: Header information (\makeheader) must be placed BEFORE \begin{document}, not after it.

Formatting:
- Use template commands and environments
- Make URLs clickable with \href
- Escape % as \%
- Group skills into categories with clear label
- Format projects as bullet points
- When user requests margin changes, add \geometry{margin=X} after \documentclass
- When user requests name size changes, modify the \Huge in \makeheader command
- Available name sizes: \tiny, \scriptsize, \footnotesize, \small, \normalsize, \large, \Large, \LARGE, \huge, \Huge
- Header commands (\makeheader) go BEFORE \begin{document}
