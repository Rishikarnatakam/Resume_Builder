CORE PRINCIPLES:
• Modern resume with 2 column layout - professional and clean
• Color-coded sections with modern typography
• Clean, professional formatting for ATS systems
• Structured organization with clear section hierarchy
• Smart pagination: Complete sections should not break across pages

LAYOUT FUNDAMENTALS:
• Use \begin{paracol}{2} and \end{paracol} for two-column layout
• Place header (\makecvheader) BEFORE \begin{paracol}{2}
• Use \switchcolumn to move between columns
• Use \newpagestart or \newpage\end{paracol}\begin{paracol}{2} for new pages
• Keep sections intact - don't break them across pages

MARGIN REQUIREMENTS:
• ALWAYS use exactly 0.5 inch margins for all sides (top, bottom, left, right) can be changed wiht user's request 
• Use \geometry{margin=0.5in} AFTER \documentclass{altacv}
• Use consistent 0.5 inch margins for maximum content space while maintaining readability
• Use \raggedbottom to prevent footer expansion

CONTENT ORGANIZATION:
• Use \cvsection{} for section headers
• ALWAYS add an empty line after every \cvsection{} command
• Use \cvevent{}{}{}{} for experiences, projects, education
• Include relevant technologies and achievements
• Add links using \href{url}{text} when available
• Group related content logically
• NO PHOTOS: Do not include any photo commands (\photoR, \photoL, \photo) unless user explicitly provides a photo and requests it to be added

INTELLIGENT SPACING:
• Add small spacing after \makecvheader for visual separation (\smallskip or \vspace{0.1in})
• Add empty line after every \cvsection{} command
• Use good visual spacing between sections for readability
• Sections automatically have proper spacing built into the template

SKILLS FORMATTING:
• Skills section: Use grouped text format, NOT \cvtag boxes
• AUTOMATICALLY GROUP skills from user's flat list into logical categories
• Use category names that make sense for the skills (Programming Languages, Frameworks, Tools, Databases, Cloud, etc.)
• Example: "Programming Languages : Python, JavaScript, Java
            Frameworks : React, Flask, Django
            Tools : Git, Docker, AWS
            Databases : MySQL, PostgreSQL"
• Intelligently categorize skills - don't just list them randomly
• Project technologies: Continue using \cvtag{} boxes for individual technologies
• Group similar skills together logically (e.g., all programming languages together, all frameworks together)

COMMAND DEPENDENCY REQUIREMENTS:
