TEMPLATE: AltaCV

## QUICK START
- **Layout:** 2-column, modern, professional, clean
- **Main commands:**
  - \cvsection{Section} — Section header
  - \cvevent{Title}{Org}{Date}{Location} — Experience/education entry
  - \cvtag{Skill} — Tag for project technologies
  - \begin{paracol}{2} ... \end{paracol} — Two-column layout
  - \switchcolumn — Move to right column
  - \makecvheader — Header (inside document)
- **Section order:** Header → Education → Certifications → [switch column] → Projects → Skills
- **Margins:** Always use \geometry{margin=0.5in} after \documentclass{altacv}
- **Skills:** Group by category (see example below)

---

## COMMAND USAGE EXAMPLES
- Section header: `\cvsection{Projects}`
- Experience: `\cvevent{Software Engineer}{Company}{2022--2024}{Remote}`
- Project technologies: `\cvtag{React}`
- Two-column start: `\begin{paracol}{2}`
- Switch column: `\switchcolumn`
- End columns: `\end{paracol}`

---

## MINIMAL WORKING EXAMPLE
```latex
\documentclass{altacv}
\geometry{margin=0.5in}
\begin{document}
\makecvheader
\begin{paracol}{2}
% Left column
\cvsection{Education}
\cvevent{BSc Computer Science}{Uni}{2020--2024}{City}
\cvsection{Certifications}
...certifications...
\switchcolumn
% Right column
\cvsection{Projects}
\cvevent{Resume Builder}{Self}{2023}{Remote}
\begin{itemize}
  \item Built a resume app
\end{itemize}
\cvsection{Skills}
Programming Languages: Python, JavaScript\\
Frameworks: React, Flask\\
Tools: Git, Docker
\end{paracol}
\end{document}
```

## CRITICAL DO'S AND DON'TS
| Do | Don’t |
|----|-------|
| Use only current template commands | Change \documentclass |
| Group skills by category | List skills flat or randomly |
| Keep sections contiguous | Split/interleave sections |
| Use \switchcolumn once | Switch columns multiple times |
| Omit empty sections | Add fake/placeholder info |
| Use \href{url}{text} for links | Add comments in LaTeX |

```

Frameworks: React, Flask, Django
Tools: Git, Docker, AWS
Databases: MySQL, PostgreSQL
```
**Bad:**
```
Python, JavaScript, Java, React, Flask, Django, Git, Docker, AWS, MySQL, PostgreSQL
```

## TROUBLESHOOTING / FAQ
- **Section won’t fit?** Start it on a new page (left column).
- **Missing command?** Define it based on template patterns.
- **Skills not grouped?** Use common categories: Programming Languages, Frameworks, Tools, Databases, Cloud.
- **Output not compiling?** Check for unmatched \begin/\end and section environments.
- **No photos:** Only add photo commands if user provides a photo and requests it.

---

## DETAILED RULES (REFERENCE)
- Use \makecvheader inside document for header.
- Add empty line after every \cvsection{}.
- Use bullet points for project details (\begin{itemize} ... \end{itemize}).
- Never break, split, or interleave sections across columns/pages unless absolutely necessary.
- Each section must be a single, contiguous block.
- Never output comments or explanations in LaTeX code.
- Compile with pdflatex.
- Maintain section integrity and professional spacing.
- ATS-friendly formatting throughout.
